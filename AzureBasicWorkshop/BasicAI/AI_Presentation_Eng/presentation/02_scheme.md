# Scheme: The 6-Layer AI Stack

---

## One-Page Architecture

```text
WORKFLOWS   - deterministic orchestration
AGENTS      - autonomous planning/execution
MCPS        - protocol for tools and data
SKILLS      - reusable capability modules
INSTRUCTIONS- persistent behavioral rules
PROMPTS     - one-shot user requests
```

---

## Quick Definitions

- Prompt: one request in natural language.
- Instruction: persistent rules for how AI should behave.
- Skill: reusable task-specific capability.
- MCP: standard protocol to connect tools/data.
- Agent: autonomous goal-driven executor.
- Workflow: predefined reliable process pipeline.

---

## Build-Up Logic

```text
Prompt + persistence         -> Instruction
Instruction + modularity     -> Skill
Skill + external access      -> MCP-enabled execution
MCP + autonomy               -> Agent
Agent + deterministic control-> Workflow / Hybrid orchestration
```

---

## Level Table

| Level | Name | Essence |
|------|------|---------|
| 1 | Prompt | Ask once, get answer |
| 2 | Instruction | Keep behavior stable |
| 3 | Skill | Reuse how-to expertise |
| 4 | MCP | Access real tools/data |
| 5 | Agent | Plan and act autonomously |
| 6 | Workflow | Ensure predictable outcomes |

---

## Key Distinctions

- Prompt vs Instruction: one-off vs persistent.
- Instruction vs Skill: general behavior vs specific ability.
- Skill vs MCP: capability vs access.
- MCP vs Agent: tools vs decision-maker.
- Agent vs Workflow: flexibility vs predictability.
