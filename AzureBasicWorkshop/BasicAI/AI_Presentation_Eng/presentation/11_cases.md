# Practical Cases

## Case 1: Customer Support Automation

### Problem
A company handles thousands of tickets daily with inconsistent response quality.

### Solution by maturity
1. Prompt-only: quick experiments, low consistency.
2. Instructions + MCP: improved consistency and live data access.
3. Workflow + Skills + MCP (+ human review): production-grade reliability.

### Result
- higher automation rate
- better SLA compliance
- lower operator load

---

## Case 2: AI Code Review in CI

### Problem
Manual code review is slow and uneven.

### Solution
- Instructions for review style and policy
- Skills for bug/security/test checks
- Workflow in CI to run and post findings

### Result
- faster review cycles
- standardized quality gates
- fewer critical defects merged

---

## Case 3: Labor Market Research Evolution

### Problem
HR needs weekly market intelligence.

### Evolution
1. Prompt summary (quick but shallow)
2. MCP-enhanced data pull (live but manual)
3. Agent research run (deep but costly)
4. Scheduled workflow with checks (stable and scalable)

### Result
Balanced architecture with repeatable high-quality reports.

---

## Cross-Case Lesson

Best outcomes come from layered architecture:
- start simple
- add only required complexity
- keep governance and observability from day one

---

## Speaker Notes

- Ask audience which architecture they would pick for each case.
