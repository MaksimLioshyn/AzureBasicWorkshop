# Overview and Navigation
## Prompts vs Instructions vs Skills vs MCPs vs Agents vs Workflows

---

## Main Idea

Modern AI work is a ladder of control levels, from a single prompt to robust workflows. These levels are not competitors. They are layers of one system, where each next level adds capability, reliability, or autonomy.

## Complexity Ladder

```text
Prompts -> Instructions -> Skills -> MCPs -> Agents -> Workflows
  simple                                                          powerful
```

```text
WORKFLOWS   : deterministic orchestration and reliability
AGENTS      : autonomous planning and execution
MCPS        : real-world tools and data access
SKILLS      : reusable domain capabilities
INSTRUCTIONS: persistent behavioral constraints
PROMPTS     : one-shot user request
```
