# 📋 Examples for the Instructions block

---

## Why is this file needed?

This file is needed for a visual transition from a one-time prompt to permanent rules of behavior for the model.

---

## Example 1. Corporate response style

### System instructions
```text
Always answer in Russian.
Don't use colloquial jargon.
If the question concerns personal data, first warn about the security policy.
At the end of your answer, add a short “Next step” block.
```

### What to show the audience
- This is not a separate one-time request, but a permanent layer of politics.
- The same user question is now processed according to the same rules.
- Instructions help the entire team achieve the same assistant behavior style.

### Conclusion
Instructions are needed where the chaos of personal prompts already interferes with quality.

---

## Example 2: Safe Reply Policy

### System instructions
```text
Do not propose actions to delete or change product data without confirmation.
If there is not enough data, clearly write: “Insufficient data.”
After that, list what exactly needs to be clarified.
```

### What to show the audience
- Instructions limit risky responses.
- They are useful even before the advent of Skills, MCP and Agents.
- But by themselves they do not provide access to real data and external systems.

### Conclusion
Instructions answer the question “how to always behave”, not “how to solve one specific problem”.

---

## How to use on slides

- Show one user request without instructions and with instructions.
- Emphasize the difference from prompt: prompt is one-time, instructions are permanent.
- Use this file toas a bridge to the Skills block.
