# Примеры для Live Demo: 5 Шагов

Эта папка содержит готовые примеры для демонстрации прогрессии от простого `prompt` до полного `workflow`.

## 📋 Структура папки

```
example/
├── step-1-basic-prompt.txt           ← Шаг 1: Простой prompt
├── .github/
│   ├── copilot-instructions.md       ← Шаг 2: Глобальные инструкции
│   ├── skills/
│   │   ├── code-analyzer.skill.md    ← Шаг 3a: Первый skill
│   │   └── documentation-generator.skill.md  ← Шаг 3b: Второй skill
│   └── agents/
│       └── support-agent.agent.md    ← Шаг 4: Agent для поддержки
└── step-5-workflow-diagram.md        ← Шаг 5: Диаграмма workflow
```

## 🎯 Как использовать в демонстрации

### Шаг 1: Базовый Prompt (5 минут)
1. Откройте Copilot Chat (`Ctrl+Shift+I`)
2. Скопируйте prompt из `step-1-basic-prompt.txt`
3. Покажите, как Copilot отвечает без инструкций
4. **Вывод**: базовая функциональность, но без контекста проекта

### Шаг 2: Добавляем Instructions (5 минут)
1. Создайте файл `.github/copilot-instructions.md`
2. Скопируйте содержимое из примера
3. Задайте тот же вопрос в chat
4. Покажите разницу в ответе (русский язык, практичные примеры)
5. **Вывод**: Instructions улучшают качество ответов

### Шаг 3: Подключаем Skills (5 минут)
1. Создайте папку `.github/skills/`
2. Добавьте два skill файла из примеров
3. Обновите `copilot-instructions.md` с упоминанием skills
4. Задайте вопрос вида: `@skill code-analyzer Проанализируй файл...`
5. **Вывод**: Skills добавляют специализированные возможности

### Шаг 4: Подключаем Agent (3 минут)
1. Создайте `.github/agents/support-agent.agent.md`
2. Скопируйте содержимое из примера
3. Вызовите agent: `@support-agent Объясни мне...`
4. Покажите, как agent использует skills и instructions
5. **Вывод**: Agent координирует все компоненты

### Шаг 5: Показываем Workflow Диаграмму (2 минут)
1. Откройте `step-5-workflow-diagram.md`
2. Покажите Mermaid диаграмму с потоком данных
3. Объясните, как каждый слой взаимодействует
4. **Вывод**: Это полная система взаимодействия компонентов

## ⏱️ Итого: 20 минут демонстрации

- Шаг 1: 5 мин (Prompt)
- Шаг 2: 5 мин (Instructions)
- Шаг 3: 5 мин (Skills)
- Шаг 4: 3 мин (Agent)
- Шаг 5: 2 мин (Workflow)

## 💡 Ключевые моменты для демонстрации

1. **Эволюция**: от простого к сложному
2. **Синергия**: каждый уровень улучшает предыдущий
3. **Практичность**: все примеры работают в VS Code
4. **Автоматизация**: workflow делает систему умной и отзывчивой

## 🚀 Дополнительные советы

- Во время демонстрации можно открыть VS Code и показать файлы в реальном времени
- Вопросы от студентов можно использовать как натуральные примеры
- Покажите, как каждый компонент влияет на качество ответов
- Подчеркните разницу между "просто Chat" и "интегрированной системой"
