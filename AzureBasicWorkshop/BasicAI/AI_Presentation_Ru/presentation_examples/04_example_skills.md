# 🎯 Примеры для блока Skills

---

## Зачем нужен этот файл

Этот файл показывает, как из набора повторяющихся prompt'ов и правил получается переиспользуемый skill.

---

## Пример 1. Skill "AI Code Review"

### Вход
- diff pull request;
- при необходимости список измененных файлов;
- корпоративные правила ревью.

### Выход
- замечания по категориям:
  - Security
  - Correctness
  - Maintainability

### Что показать аудитории
- Раньше каждый разработчик формулировал свой prompt на ревью.
- Потом команда стабилизировала формат через Instructions.
- Затем это было упаковано в отдельный skill, который можно вызывать повторно.

### Вывод
Skill превращает удачную практику в стандартный модуль команды.

---

## Пример 2. Skill "Incident Summary"

### Вход
- логи;
- ошибка;
- временной диапазон;
- краткий контекст инцидента.

### Выход
- краткая причина;
- вероятное влияние;
- 3 шага диагностики;
- предложение по устранению.

### Что показать аудитории
- Skill особенно полезен в дежурной инженерной практике.
- Он снижает разброс качества между разными инженерами.
- Такой навык уже ближе к операционной библиотеке команды, чем к просто умному prompt.

### Вывод
Skills нужны там, где задача повторяется и должна выполняться одинаково хорошо.

---

## Мини-сценарий перехода от prompt к skill

1. Команда находит удачный prompt.
2. Добавляет постоянные инструкции.
3. Фиксирует шаги выполнения и формат ответа.
4. Упаковывает это в `SKILL.md`.
5. Использует навык повторно в разных задачах.
