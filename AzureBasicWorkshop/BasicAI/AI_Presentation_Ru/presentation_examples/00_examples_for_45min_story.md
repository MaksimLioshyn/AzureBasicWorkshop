# Примеры использования для 45-минутного рассказа

Этот файл содержит отдельные примеры, которые можно использовать во время презентации как практические вставки. Примеры сгруппированы по уровням зрелости.

## 1) Prompts

### Пример 1. Черновик письма клиенту
Ситуация: нужно быстро сообщить о задержке поставки.

Промпт:
"Ты специалист клиентской поддержки. Напиши короткое вежливое письмо клиенту о задержке заказа на 2 дня. Структура: 1) извинение, 2) причина без технических деталей, 3) новая дата, 4) компенсация в виде скидки 10%. Тон: деловой, дружелюбный."

Ожидаемый результат: качественный черновик за 1-2 минуты.

### Пример 2. Быстрый бриф по теме
Ситуация: сотруднику нужно быстро понять незнакомую тему.

Промпт:
"Объясни тему 'Model Context Protocol' для начинающего разработчика. Формат: 5 тезисов, затем 1 простой пример использования, затем 3 частые ошибки."

Ожидаемый результат: стартовое понимание без долгого ресерча.

## 2) Instructions

### Пример 1. Корпоративный стиль ответов
Системные инструкции:
- Всегда отвечай на русском языке.
- Не используй разговорный жаргон.
- Если вопрос касается персональных данных, сначала предупреди о политике безопасности.
- В конце ответа добавляй краткий блок "Следующий шаг".

Эффект: единый стиль ассистента для всех сотрудников.

### Пример 2. Политика безопасных ответов
Системные инструкции:
- Не предлагай действий с удалением/изменением прод-данных без подтверждения.
- Если данных недостаточно, явно пиши "Недостаточно данных" и перечисляй, что нужно уточнить.

Эффект: снижение риска рискованных ответов и ложной уверенности.

## 3) Skills

### Пример 1. Skill "AI Code Review"
Вход: diff pull request.
Выход: список замечаний по категориям:
- Security
- Correctness
- Maintainability

Эффект: одинаковая структура review и ускорение первичной проверки.

### Пример 2. Skill "Incident Summary"
Вход: логи, ошибка, временной диапазон.
Выход:
- краткая причина,
- вероятное влияние,
- 3 шага диагностики,
- предложение по устранению.

Эффект: единый формат разбора инцидентов для дежурной команды.

## 4) MCPs

### Пример 1. Поддержка клиентов + CRM
Поток:
1. Пользователь вводит номер заказа.
2. Ассистент через MCP читает статус из CRM.
3. Формирует ответ с актуальной датой доставки.

Эффект: ответы на фактах, а не на предположениях.

### Пример 2. Dev Assistant + GitHub
Поток:
1. Ассистент через MCP получает список открытых PR.
2. Формирует краткий daily summary по рискам и блокерам.

Эффект: экономия времени на ручной сбор статусов.

## 5) Agents

### Пример 1. Агент конкурентного анализа
Цель: за 20 минут собрать обзор по 5 конкурентам.
Шаги агента:
1. Ищет источники.
2. Сравнивает признаки.
3. Делает таблицу различий.
4. Формирует вывод и зоны неопределенности.

Эффект: ускорение исследовательских задач.

### Пример 2. Агент подбора обучающего плана
Цель: составить план обучения команды на 3 месяца.
Шаги:
1. Анализ текущего стека.
2. Поиск пробелов компетенций.
3. Формирование дорожной карты по неделям.

Эффект: быстрое создание адаптивного плана развития.

## 6) Workflows

### Пример 1. Workflow обработки обращений
Шаги:
1. Классификация запроса.
2. Извлечение данных через MCP.
3. Генерация ответа.
4. Проверка confidence score.
5. Отправка или эскалация оператору.

Эффект: стабильный SLA и прозрачность процесса.

### Пример 2. Workflow еженедельной аналитики вакансий
Шаги:
1. Сбор данных из источников.
2. Нормализация.
3. Проверка качества.
4. Генерация отчета.
5. Публикация и архив.

Эффект: регулярная аналитика по расписанию без ручного хаоса.

## 7) Антипаттерны (для обсуждения)

### Антипаттерн 1. "Агент на всё"
Проблема: рост стоимости, непредсказуемое поведение.
Контрмера: агент только в сложных узлах, остальное — workflow.

### Антипаттерн 2. Prompt-only в production
Проблема: нет повторяемости и контроля качества.
Контрмера: добавить instructions + skills + метрики качества.

### Антипаттерн 3. Over-privileged MCP
Проблема: риск инцидентов безопасности.
Контрмера: least privilege + аудит всех вызовов + approval для опасных операций.

## Рекомендуемый тайминг вставки примеров
- Блоки Prompts/Instructions/Skills/MCP/Agents/Workflows: по 1 примеру в каждом блоке (примерно 1 минута на пример)
- Кейсовые слайды: по 1 расширенному примеру (1-2 минуты)
- Итого примеры дают 10-12 минут в составе общего 45-минутного рассказа.
