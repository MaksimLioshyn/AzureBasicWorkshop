# 💬 Примеры для блока Prompts

---

## Зачем нужен этот файл

Этот файл выносит примеры для блока Prompts в отдельный материал, чтобы спикер мог:
- не перегружать основной теоретический файл;
- быстро выбрать 1-2 демонстрации под аудиторию;
- показать, как из сырого запроса рождается качественный prompt.

---

## Пример 1. Черновик письма клиенту

### Ситуация
Нужно быстро сообщить клиенту о задержке поставки.

### Базовый prompt
```text
Напиши письмо клиенту о задержке заказа.
```

### Улучшенный prompt
```text
Ты специалист клиентской поддержки.
Напиши короткое вежливое письмо клиенту о задержке заказа на 2 дня.
Структура:
1. Извинение
2. Причина без технических деталей
3. Новая дата доставки
4. Компенсация в виде скидки 10%
Тон: деловой, дружелюбный.
Язык: русский.
```

### Что показать аудитории
- Как меняется качество ответа после добавления структуры.
- Что prompt сам по себе еще не гарантирует единый корпоративный стиль.
- Почему для массового использования позже понадобятся Instructions.

### Вывод
Prompt хорош для быстрого старта, когда нужно получить черновик за 1-2 минуты.

---

## Пример 2. Быстрый бриф по теме

### Ситуация
Сотруднику нужно быстро понять незнакомую тему перед встречей.

### Prompt
```text
Объясни тему "Model Context Protocol" для начинающего разработчика.
Формат:
1. 5 тезисов
2. 1 простой пример использования
3. 3 частые ошибки
```

### Что показать аудитории
- Prompt может резко сократить время на вход в тему.
- Он особенно полезен как интеллектуальный черновик, а не как окончательный источник истины.
- При вопросах с высокой ценой ошибки нужно проверять факты и источники.

### Вывод
Prompts отлично работают как быстрый слой исследования и подготовки.

---

## Как использовать на слайдах

- В короткой версии выступления: взять только один пример.
- В полной версии: показать два prompt и сравнить качество ответа.
- В live-demo: сначала ввести короткий prompt, затем тут же усилить его структурой.
