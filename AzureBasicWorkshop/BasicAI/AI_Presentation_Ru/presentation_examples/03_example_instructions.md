# 📋 Примеры для блока Instructions

---

## Зачем нужен этот файл

Этот файл нужен для наглядного перехода от разового prompt к постоянным правилам поведения модели.

---

## Пример 1. Корпоративный стиль ответов

### Системные инструкции
```text
Всегда отвечай на русском языке.
Не используй разговорный жаргон.
Если вопрос касается персональных данных, сначала предупреди о политике безопасности.
В конце ответа добавляй краткий блок "Следующий шаг".
```

### Что показать аудитории
- Это не отдельная разовая просьба, а постоянный слой политики.
- Один и тот же пользовательский вопрос теперь обрабатывается по единым правилам.
- Инструкции помогают всей команде получать одинаковый стиль поведения ассистента.

### Вывод
Instructions нужны там, где хаос персональных prompt'ов уже мешает качеству.

---

## Пример 2. Политика безопасных ответов

### Системные инструкции
```text
Не предлагай действий с удалением или изменением прод-данных без подтверждения.
Если данных недостаточно, явно пиши: "Недостаточно данных".
После этого перечисляй, что именно надо уточнить.
```

### Что показать аудитории
- Instructions ограничивают рискованные ответы.
- Они полезны даже до появления Skills, MCP и Agents.
- Но сами по себе не дают доступ к реальным данным и внешним системам.

### Вывод
Instructions отвечают на вопрос "как вести себя всегда", а не "как решить одну конкретную задачу".

---

## Как использовать на слайдах

- Покажите один пользовательский запрос без instructions и с instructions.
- Подчеркните отличие от prompt: prompt разовый, instructions постоянные.
- Используйте этот файл как мост к блоку Skills.
