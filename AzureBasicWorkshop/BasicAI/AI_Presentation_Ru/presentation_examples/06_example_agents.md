# 🤖 Примеры для блока Agents

---

## Зачем нужен этот файл

Этот файл помогает показать, где заканчивается обычный вызов инструмента и начинается агентный цикл: цель, план, действие, проверка, корректировка.

---

## Пример 1. Агент конкурентного анализа

### Цель
За 20 минут собрать обзор по 5 конкурентам.

### Шаги агента
1. Ищет источники.
2. Сравнивает признаки.
3. Делает таблицу различий.
4. Формирует вывод и зоны неопределенности.

### Что показать аудитории
- Агент не просто отвечает один раз, а сам проходит цикл действий.
- Он может выбирать следующий шаг по результатам предыдущего.
- Это сильнее prompt'а и skill'а, но сложнее в контроле.

### Вывод
Агент оправдан там, где порядок действий не полностью известен заранее.

---

## Пример 2. Агент подбора обучающего плана

### Цель
Составить план обучения команды на 3 месяца.

### Шаги
1. Анализ текущего стека.
2. Поиск пробелов компетенций.
3. Формирование дорожной карты по неделям.

### Что показать аудитории
- Агент хорошо работает в адаптивных исследовательских задачах.
- Но требует ограничений по шагам, стоимости и набору инструментов.
- Агенту полезно давать Skills и MCP как рабочие примитивы.

### Вывод
Сильный агент почти всегда опирается на instructions, skills и tools.
