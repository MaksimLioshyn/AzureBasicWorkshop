# Папка с examples

В этой папке собраны все материалы с примерами в одном месте.

Состав:
- 00_examples_for_45min_story.md — исходный общий файл с примерами
- 01_cases.md — развернутые кейсы
- 02_example_prompts.md — примеры для Prompts
- 03_example_instructions.md — примеры для Instructions
- 04_example_skills.md — примеры для Skills
- 05_example_mcps.md — примеры для MCPs
- 06_example_agents.md — примеры для Agents
- 07_example_workflows.md — примеры для Workflows
- 08_example_antipatterns.md — примеры антипаттернов

Эта папка сделана как единая точка входа для подготовки блоков с примерами и live-demo.
