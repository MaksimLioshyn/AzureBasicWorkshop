## 🎯 Типичное применение по концептам

### 💬 Prompts
```
✓ Разовые вопросы и задачи
✓ Брейнсторминг и исследование
✓ Генерация контента (тексты, код, идеи)
✓ Перевод и адаптация
✓ Обучение и объяснение
✓ Quick-wins без инфраструктуры
```

### 📋 Instructions
```
✓ Корпоративные чат-боты и ассистенты
✓ Специализированные AI-продукты (HR-бот, support-бот)
✓ Настройка поведения Copilot в командах
✓ Брендирование AI под компанию
✓ Ограничение тематики для безопасности
```

### 🎯 Skills
```
✓ Стандартизированные операции команды
✓ Code review, тесты, документация в разработке
✓ Анализ и оценка (HR, финансы, юриспруденция)
✓ Модульные компоненты AI-систем
✓ Библиотека лучших практик компании
```

### 🔌 MCPs
```
✓ Интеграция AI с корпоративными системами (CRM, ERP)
✓ Работа с файловой системой и кодовой базой
✓ Доступ к базам данных в реальном времени
✓ Подключение к SaaS-сервисам (GitHub, Jira, Slack)
✓ AI-ассистент с доступом к «живым» данным
```

### 🤖 Agents
```
✓ Исследовательские задачи (конкуренты, рынок, технологии)
✓ Автоматизация сложных IT-задач (деплой, мониторинг)
✓ Персонализированные рекомендательные системы
✓ Обработка нестандартных запросов с принятием решений
✓ DevOps и IT Ops автоматизация
```

### 🔄 Workflows
```
✓ Бизнес-процессы: обработка заявок, найм, onboarding
✓ Document processing pipelines
✓ Регулярная отчётность с AI-генерацией
✓ ETL/ELT с AI-трансформациями
✓ Финансовые и юридические процессы (compliance)
✓ CI/CD с AI-проверками качества
```

## 🔗 Паттерны комбинирования

### Паттерн 1: «Умный помощник» (Copilot-стиль)
```
Instructions (кто ты и как работаешь)
    + Skills (что умеешь делать)
    + MCPs (с чем работаешь)
    = Специализированный AI-ассистент
```

### Паттерн 2: «Автопилот» (Agent-стиль)
```
Instructions (правила поведения агента)
    + Skills (набор навыков)
    + MCPs (инструменты)
    + Prompts (цель задачи)
    = Автономный агент
```

### Паттерн 3: «Фабрика» (Enterprise Workflow)
```
Workflow (управляет потоком)
    содержит AI-узлы с Instructions
    вызывает Skills на каждом шаге
    использует MCPs для данных
    = Надёжный бизнес-процесс с AI
```

### Паттерн 4: «Исследователь + Фабрика» (Гибридный)
```
Workflow (детерминированная оболочка)
    ├── Шаг 1: Agent (исследует, адаптируется)
    ├── Шаг 2: Skill (применяет стандарт)
    ├── Шаг 3: MCP (сохраняет результат)
    └── Шаг 4: Notification (уведомляет)
    = Гибкость + надёжность
```

## 💰 Сравнение по стоимости

```
Пример задачи: обработать 1000 документов

💬 Prompt (1000 × 1 вызов): 
   ~$0.5–2 (зависит от длины)

🤖 Agent (1000 × ~15 вызовов):
   ~$7.5–30 (дороже в 15x!)

🔄 Workflow с AI-узлами (1000 × 3 вызова):
   ~$1.5–6 (оптимальный баланс)
```

**Вывод:** Агенты дорогие. Для массовой обработки Workflow + точечные AI-вызовы = оптимум.

## ⚠️ Антипаттерны — типичные ошибки

| Антипаттерн | Что происходит | Правильное решение |
|-------------|---------------|-------------------|
| «Всё через агента» | Дорого, медленно, ненадёжно | Используй Workflow для повторяемых задач |
| «Зачем Instructions, промпта хватит» | Непоследовательное поведение, нарушения | Задавай правила для продакшен-систем |
| «MCP для всего» | Избыточная инфраструктура | Только там, где нужны внешние данные |
| «Skill = агент» | Навыки слишком большие и сложные | One Skill = One Responsibility |
| «Промпт вместо Workflow» | Ненадёжно, нет восстановления | Для бизнес-процессов — Workflow |
| «Agents в финансах без контроля» | Риски ошибок с реальными деньгами | Human-in-loop для критичных операций |

## 🎤 Заметки для спикера

- **Эта таблица — главный аргумент** против «что лучше». Каждый концепт лидирует в своей нише
- **Матрица «когда побеждает»** — используй как Quiz для аудитории: «какой концепт бы вы выбрали для этой ситуации?»
- **Стоимость** — эффектный момент. 15x разница между Prompt и Agent на больших объёмах — заставляет задуматься
- **Антипаттерны** — полезны для практикующих разработчиков. Многие узнают свои ошибки
- Время на этот слайд: **7–8 минут**
