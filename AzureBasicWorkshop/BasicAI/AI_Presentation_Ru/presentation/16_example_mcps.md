# 🔌 Примеры для блока MCPs

---

## Зачем нужен этот файл

Этот файл выносит в отдельный материал примеры, где AI перестает работать только на тексте и начинает использовать реальные данные и инструменты.

---

## Пример 1. Поддержка клиентов + CRM

### Поток
1. Пользователь вводит номер заказа.
2. Ассистент через MCP читает статус из CRM.
3. Формирует ответ с актуальной датой доставки.

### Что показать аудитории
- До MCP модель лишь предполагает ответ.
- После MCP ответ основан на фактических данных.
- Именно здесь особенно важны права доступа и аудит вызовов.

### Вывод
MCP нужен, когда AI должен работать не по памяти модели, а по реальной информации.

---

## Пример 2. Dev Assistant + GitHub

### Поток
1. Ассистент через MCP получает список открытых PR.
2. Смотрит статусы и блокеры.
3. Формирует daily summary для команды.

### Что показать аудитории
- MCP связывает AI с текущим состоянием проекта.
- Без него summary было бы чистой выдумкой или ручной копипастой.
- MCP хорошо показывает разницу между "умением" и "доступом к реальности".

### Вывод
Skills отвечают за способ решения, MCP отвечает за подключение к данным и действиям.

---

## Ограничение, которое стоит проговорить вслух

Не любой MCP можно поднять за 5 минут в live-demo. Для хорошей демонстрации лучше брать:
- файловый MCP;
- GitHub-подобный read-only MCP;
- простой локальный сервер без write-операций.
