# 📚 Обзор и навигация по материалам презентации
## «Prompts vs Instructions vs Skills vs MCPs vs Agents vs Workflows»

---

## 🎯 Главная идея презентации

Когда мы работаем с AI-системами, мы используем разные «уровни управления» — от простого текстового запроса до сложного автономного агента. Эти уровни не конкурируют между собой, а образуют **единую систему**, где каждый следующий уровень строится на предыдущем и добавляет новые возможности. Понимание этой иерархии — ключ к профессиональной работе с AI.

## 🪜 «Лестница сложности»

Визуальная схема перехода от самого простого к самому мощному:

```
                                    ┌─────────────────────┐
                                    │    🔄 WORKFLOWS      │  ← Детерминированные пайплайны
                                    │  Высокая надёжность  │
                                    └──────────┬──────────┘
                                               │ включает
                                    ┌──────────▼──────────┐
                                    │     🤖 AGENTS        │  ← Автономные системы
                                    │  Высокая автономность│
                                    └──────────┬──────────┘
                                               │ использует
                                    ┌──────────▼──────────┐
                                    │      🔌 MCPs         │  ← Инструменты и данные
                                    │  Доступ к реальности │
                                    └──────────┬──────────┘
                                               │ применяет
                                    ┌──────────▼──────────┐
                                    │     🎯 SKILLS        │  ← Модульные навыки
                                    │  Переиспользование   │
                                    └──────────┬──────────┘
                                               │ управляет
                                    ┌──────────▼──────────┐
                                    │  📋 INSTRUCTIONS     │  ← Системные правила
                                    │  Постоянное поведение│
                                    └──────────┬──────────┘
                                               │ базируется
                                    ┌──────────▼──────────┐
                                    │     💬 PROMPTS       │  ← Разовые запросы
                                    │  Простейший уровень  │
                                    └─────────────────────┘
```

### Ось «Простота ↔ Автономность/Мощность»

```
Простота  │                                        │ Мощность
──────────┼────────────────────────────────────────┼──────────
Prompts   │→ Instructions → Skills → MCPs → Agents → Workflows
          │
Быстрый   │                                        │ Сложная
старт     │                                        │ настройка
```

## 📊 Краткая характеристика каждого уровня

| Уровень | Суть в одном предложении | Аналогия |
|---------|--------------------------|----------|
| **Prompts** | Разовый текстовый вопрос или задача | Звонок другу за советом |
| **Instructions** | Постоянные правила поведения AI | Должностная инструкция сотрудника |
| **Skills** | Переиспользуемый модульный навык | Профессиональная компетенция |
| **MCPs** | Стандартный протокол подключения инструментов | USB-разъём для AI |
| **Agents** | Автономная система с принятием решений | Самостоятельный сотрудник |
| **Workflows** | Детерминированная последовательность шагов | Конвейер / рецепт |

## 🗺️ Как пользоваться материалом

### Для подготовки к выступлению:
1. Прочитай **01_introduction.md** — для понимания контекста
2. Изучи **02_scheme.md** — для общей картины
3. Проработай файлы **03–08** — ядро презентации, по одному концепту каждый
4. Просмотри **09_comparison.md** — для ответов на вопросы сравнения
5. Используй **11_cases.md** — для живых примеров на аудиторию
6. Подключай **13-19** — если хочешь вынести примеры в отдельные слайды или appendix
7. Используй **20_local_demo_in_vscode.md** — если хочешь провести живую локальную демонстрацию по шагам

### Для быстрой подготовки (экспресс):
- **02_scheme.md** → общая схема (10 мин)
- Секции «Аналогия» в файлах 03–08 (20 мин)
- **09_comparison.md** → таблица (5 мин)
- **10_when_to_use.md** → практика (10 мин)

### Для углублённого изучения:
- Читай все файлы последовательно, начиная с 01
- Обращай особое внимание на секции «Сравнение с соседними концептами»
- Прорабатывай примеры кода в файлах 03–08
