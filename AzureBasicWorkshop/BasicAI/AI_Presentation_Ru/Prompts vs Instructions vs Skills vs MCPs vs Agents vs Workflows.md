# Инструкция по созданию презентации: «Prompts vs Instructions vs Skills vs MCPs vs Agents vs Workflows»

## 🎯 Цель
Создать набор файлов с детальным материалом для презентации, по которому можно полноценно подготовиться к выступлению и работе с темой. Каждый файл = один раздел с обширным содержанием.

---

## 📁 Структура файлов
Создай следующие файлы в папке `presentation/`:

presentation/ ├── 00_overview.md # Общий обзор и навигация ├── 01_introduction.md # Введение ├── 02_scheme.md # Обзорная схема ├── 03_prompts.md # Prompts ├── 04_instructions.md # Instructions ├── 05_skills.md # Skills ├── 06_mcps.md # MCPs ├── 07_agents.md # Agents ├── 08_workflows.md # Workflows ├── 09_comparison.md # Сравнительная таблица ├── 10_when_to_use.md # Когда что использовать ├── 11_cases.md # Примеры и кейсы └── 12_conclusion.md # Заключение

---

## 📋 ОБЩИЕ ТРЕБОВАНИЯ К КАЖДОМУ ФАЙЛУ

Каждый файл-концепт (03–08) ДОЛЖЕН содержать следующие секции:

1. **Заголовок и краткое определение** (1-2 предложения)
2. **Подробное объяснение** (что это простыми словами + технически)
3. **Аналогия из реальной жизни** (для лёгкого понимания)
4. **Как это работает** (механика, схема, этапы)
5. **Примеры кода/использования** (минимум 2-3 примера)
6. **Плюсы** (минимум 4 пункта с пояснениями)
7. **Минусы / ограничения** (минимум 3 пункта)
8. **Когда использовать / когда НЕ использовать**
9. **Сравнение с соседними концептами** (чем отличается)
10. **Заметки для спикера** (что подчеркнуть на выступлении)
11. **Возможные вопросы аудитории + ответы** (3-5 вопросов)

**Объём:** каждый файл-концепт — не менее 300-400 строк качественного материала.

**Стиль:** понятный, с примерами, без воды, технически корректный.
